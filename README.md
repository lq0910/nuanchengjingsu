# 暖城竞速

Three.js 双桥街机赛车。两座桥按用户参考图建模，不是测绘或工程复刻；赛道为适合游戏的虚构环线。

## 运行

在项目目录执行（Node.js 22.12+）：

```sh
npm ci
npm run dev
```

打开终端打印的本地地址。执行 `npm test` 可运行赛道和比赛规则测试；`npm run build` 生成 `dist/`，可用静态 HTTP 服务部署，不要直接双击其中的 HTML。

## 操作

选择一座桥作为起跑点，在发车页设置 1–5 圈、1–8 辆赛车（含玩家，默认 3 辆）。单圈约 1.99 公里，两种出发方式都会经过两座桥和两处飞跃坡。最快完赛成绩按起跑点、圈数、赛车数量、天气和动态事件模式分别保存在浏览器。

- `W` / `↑` / `Space` 加速，`S` / `↓` 刹车。
- `A` / `D` 或 `←` / `→` 转向，`Shift` 使用氮气。
- 发车倒计时或比赛中，在赛道画面上按住鼠标右键拖动。横向可绕车查看 360°，纵向可调整俯仰；松开回到跟车视角。环视时可照常驾驶。
- 发车倒计时起，四旋翼无人机在玩家车辆前上方跟拍。右侧「无人机直播」显示实时航拍，点击标题可收起或展开。
- 高速冲过坡顶时车辆会短暂腾空，空中的转向和刹车效果减弱，落回下坡后恢复抓地力。
- `Esc` 暂停或恢复。手机默认用左侧摇杆转向，右侧控制油门、刹车和氮气。
- 在右上角或暂停菜单打开「转向设置」，可以选择摇杆、方向按键或体感，并设置转向灵敏度。体感需要 HTTPS 或本机 localhost，以及浏览器传感器权限。
- 右上角切换日夜；夜间可看见斜拉桥的蓝塔和灯光索线。
- 发车页的「天气」可选择晴天或雨天，选择会保存在浏览器。雨天可与日夜自由组合。湿路刹车距离更长，高速过弯容易外滑。
- 发车页的「动态事件」默认混合安排酒驾临检和施工并道，也可单独体验或关闭。临检限速 45 km/h，超速会停车等待放行。施工时按提示并入开放车道，驶入封闭侧会掉速。
- 菜单、车库和转向设置有操作音；起跑倒计时自动轰油，也可按油门拉高转速。比赛中保留配乐，叠加动态引擎、刹车、氮气和撞击声。右上角 `SOUND ON / OFF` 同时控制配乐与音效。
- 行驶中按住油门和氮气，双排气会喷出蓝白尾焰；松开、刹车或氮气耗尽后停止喷射。
- 双车追尾会交换速度，侧擦会把车辆推开；贴着护栏时车身不会被挤出赛道。

## 车库

赛前点「车库」查看 Audi RS5。选择江潮 GT、白翼经典、墨夜拉力或原厂纯色，也可用颜色选择器自订车漆。前后车牌同步更新，支持最多九个汉字、字母、数字或常用分隔符。拖动车辆预览可转动视角。车辆和转向设置会保存在当前浏览器。

在「外观改装」中可选同色鸭尾、GT 低位尾翼、亮银 Y 辐或钛灰弧形十辐轮毂，也能恢复原厂。两款尾翼均随车漆变色，选配会切到后视或侧视，配件会保存并带入比赛。

## 模型

车辆直接来自项目内的 `Audi+RS5+Coupe+2020+CGT.blend`。网页使用已经导出的 `public/audi-rs5.glb`，运行不需要 Blender，也不依赖在线模型或字体。需更新车模时可使用 Blender 5.3 导出（macOS 示例）：

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b 'Audi+RS5+Coupe+2020+CGT.blend' -P scripts/export-car.py
```

当前模型只有车外部件，没有可用的座舱内饰，因此游戏未提供车内驾驶视角。

公交、出租车、骑行者和行人由 Three.js 生成。每场发车时重新分配车型、位置、配色和速度，交通实体可与玩家和 AI 赛车发生碰撞。`public/traffic/` 中有同源 GLB 底模，可直接导入 Blender。修改模型后可运行 `node scripts/export-traffic.js` 重新导出。
